# PhotoCraft 0.7.0 for AROS — preview1

Experimental build for x86_64 AROS ABIv11.

PhotoCraft provides layers, masks, painting, undo and redo, and PSD and PNG workflows. This experimental build includes the editor and `photocraft-cli`.

Unpack the archive into a drawer and double-click the PhotoCraft icon. From a Shell, run `Stack 4000000` before starting `PhotoCraft`.

Use file names without accented letters. System TrueType fonts appear in the font list but render with a built-in font. Image clipboard exchange and opening files dropped onto the window are unavailable. Large documents can be slow.

If replacing a saved file fails after the old file has been removed, the new contents remain in a temporary file. The error message gives its name.
